# Install FEFC Collection on a Toshiba Fire TV

1. **Turn on Developer Options.** Home > Settings > My Fire TV > About. Click the device name (the first line, for example "Fire TV Edition") 7 times quickly until it says "No need, you are already a developer."
2. Back out one screen. Developer Options now shows under My Fire TV. Open it and make sure **ADB debugging** is on.
   (On newer Fire OS the "Apps from Unknown Sources" switch is here too; if you see it, turn it on.)
3. **Install Downloader.** Press Home, choose Find > Search, type "Downloader" (orange icon, by AFTVnews), and Get/Download it.
4. **Allow Downloader to install apps.** Settings > My Fire TV > Developer Options > Install unknown apps > turn **Downloader** on.
5. **Open Downloader**, allow it access to storage if asked, then type this in the URL box and press Go:

   `https://collection.faneditfanclub.com/firetv/FEFC-Collection.apk`

   (Backup address: the GitHub Release at `https://github.com/FanEditFanClub/fefc-collection/releases/latest`. The repo is private, so that link only works if you can sign in to GitHub, which Downloader can't. Use the address above.)
6. When the download finishes, choose **Install**, then **Open** (or **Done**). When asked, delete the APK file to free up space.
7. Find the app: Home > Your Apps & Channels > FEFC Collection (also in the app row). Hold the Home button to move it to the front.

**Updates:** the web app updates itself, so nothing to do. Only a new APK (rare) needs the same steps; it installs over the old one.

**Controls:** D-pad and Select to browse. Back goes back (twice on the Home screen to exit). Menu (three lines) opens search. Play/Pause works in the player.

**Syncing My List on the TV:** open My List, choose **Sync My List**, then pick Google TV code (enter the code at google.com/device on your phone), Scan a QR code (approve on your phone), or 6-digit sync code (create a code on another device and enter it on the TV with the remote).
