Install FEFC on a Samsung TV

This is the free way. You need a free Samsung account, Tizen Studio on a Windows or Mac computer, and the TV on the same Wi-Fi. The app is FEFC 0.6.3 Beta. The TV shows it as FEFC, with the FEFC icon. The picture is the live site. You sign the package yourself. This project does not include a Samsung certificate.

These steps follow Samsung’s current TV device page and certificate page. Button names move between Tizen Studio versions. Where this page is not sure, it says so. Nothing here was installed on a real Samsung TV.

What you need

  • A Samsung smart TV and a Windows or Mac computer on the same Wi-Fi.
  • A free Samsung account. Create one at account.samsung.com if you do not have one. You do not need a paid Samsung partner account.
  • The unsigned file FEFC.wgt. It is not in the Samsung store. The person who runs FEFC can send it to you. If you can open the project’s GitHub Actions, download the artifact named fefc-tizen. That zip contains FEFC.wgt. Publishing that file to the website is still turned off, so there is no public download link yet.

1. Install Tizen Studio

  1. Download Tizen Studio from developer.tizen.org. Use the installer for Windows or Mac. Install it and open it once so it can finish setup.
  2. Open Tools > Package Manager (it may also appear as Tizen Package Manager).
  3. Open the Extension SDK tab. Install TV Extensions and Samsung Certificate Extension. Samsung’s TV extension download page listed TV Extension 10.0.0 on February 26, 2026. Install the TV extension Package Manager offers. You do not need the TV emulator to put the app on a real TV.
  4. If Package Manager also lists Certificate Manager or Web CLI under the main SDK and they are not installed, install those too. The sign step needs Certificate Manager. The command-line alternative needs the tizen command.

2. Turn on Developer Mode on the TV

Samsung’s current TV device page says:

  1. On the TV, open Smart Hub, then the Apps panel.
  2. Go to App Settings. On some sets you can type the numbers on the Apps screen itself, without opening App Settings.
  3. With the remote, enter 12345. A developer-mode box opens.
  4. Switch Developer mode to On.
  5. Enter the IP address of the computer, not the TV, and confirm.
  6. Reboot the TV when it asks. After the reboot, open Apps. Develop Mode should be marked at the top of that screen.

If 12345 does nothing, try 123456. Older write-ups use that code on some sets. Samsung’s current TV device page only documents 12345, so which years use 123456 is not certain here.

The computer’s IP is in its network settings. The TV’s IP is under the TV’s network or connection status. You need both, and they must be on the same network.

3. Connect the TV in Device Manager

  1. In Tizen Studio, open Tools > Device Manager.
  2. Open Remote Device Manager and press +.
  3. Name the TV anything you will recognize. Enter the TV’s IP address. Leave the port as the number the window already shows. Samsung’s guide says the port is filled in for you. Many installs use port 26101, but if the window shows a different port, keep that one.
  4. Add the TV, then switch its Connection to On. It should show as connected.
  5. If Device Manager offers Permit to install applications, turn that on. Samsung’s FAQ says you can also right-click a folder of the connected TV and choose that item.

4. Find the TV’s DUID

The DUID is the TV’s id. The certificate will only install on TVs whose DUID is in it.

  • In Device Manager, right-click the connected TV and choose DUID, if that item is there. Copy it.
  • Samsung’s certificate page also says: on the TV, open Menu > Support > Contact Samsung > Unique Device ID.

Write the DUID down. A second TV needs its own DUID added later. The exact menu on the TV moves by year. If neither place shows a DUID, connect the TV first and look again in Device Manager. This page cannot list every year’s menu.

5. Create your Samsung certificate

This certificate stays on your computer. Do not send it to anyone, and do not put it in the FEFC project.

  1. In Tizen Studio, open Tools > Certificate Manager. If a migration box appears, choose Cancel.
  2. Press +. Choose Samsung, then TV, then Next.
  3. Name the profile, for example FEFC.
  4. Create a new author certificate. Fill in the name and password it asks for. Sign in with your Samsung account when it asks. Save the backup where you will find it again. The author file is usually named author.p12.
  5. Create a new distributor certificate. If it asks for a privilege level, choose Public. That is the free one. Partner is for companies in Samsung’s partner program. The privilege labels can differ by Studio version. Pick the choice that does not ask for a partner id.
  6. Add this TV’s DUID. Type it, or press + next to the connected TV if it is listed.
  7. Finish. This profile should be the active one.

Keep the author certificate. An update has to be signed with the same author certificate. A different author certificate looks like a different app, and the TV may refuse to replace FEFC.

6. Sign the package and install it

Do this in Tizen Studio. The command line is lower down if you would rather use that.

  1. In the Tizen Studio menu, choose File > Import > Tizen > Tizen project.
  2. Choose Select archive file and pick FEFC.wgt. If it asks for a platform, pick the TV platform you installed. Finish.
  3. If the import refuses to reuse the name FEFC because a project of that name already exists, rename the old project first. Samsung’s FAQ says the import cannot rename the project for you.
  4. Right-click the imported project and build a signed package. The menu wording varies. Look for Build Signed Package, or Package, while the FEFC certificate profile is active. The result is a new .wgt that contains signature files. The file you started with does not.
  5. With the TV’s connection On, right-click the project and choose Run As > Tizen Web Application. That installs it and opens it.
  6. On the TV, open Apps. FEFC should be there, with the FEFC icon. The screen is the FEFC collection. The remote arrows, Enter, and Back move through it. If the TV has Samsung’s video player, playback uses that. If it does not, the page plays in the browser instead.

The same install from a command line

Only if Tizen Studio’s menus will not sign the file. Open a terminal where the tizen command works. It lives under the Tizen Studio tools folder. The profile name is the one you created.

tizen package -t wgt -s FEFC -- FEFC.wgt
sdb connect TV-IP
tizen install -n FEFC.wgt -t TV-NAME

Replace FEFC with your profile name, TV-IP with the television’s address, and TV-NAME with the name you gave it in Device Manager. Some Studio versions want tizen package --type wgt instead of -t wgt. If the command is rejected, run tizen package --help on that computer and follow its syntax. The signed file is the one you install, not the unsigned one.

Install a newer FEFC later

  1. Get the new FEFC.wgt. Its FEFC version is the same words as the other FEFC apps, such as 0.6.3 Beta. The package version inside the file is three numbers, such as 0.6.51 for build 51. That third number goes up when a newer build is made, which is what lets the TV replace the old app.
  2. Sign it with the same author certificate and a distributor certificate that still lists this TV’s DUID.
  3. Install it the same way. Same app id (fefccollec), higher three-number version, same author certificate: the TV replaces FEFC. It does not add a second icon.

The TV cannot install the new file by itself. When a newer version is published, FEFC on the TV can tell you. The install still happens on the computer.

If something goes wrong

  • Developer Mode is off. Open Apps and check for “Develop Mode” at the top. If it is gone, turn Developer Mode on again, enter the computer’s IP, and reboot. Samsung’s current guide does not give one expiry time for every TV. Some sets drop the setting after a software update or after the power has been off. Check the switch before you assume the certificate is wrong.
  • The computer IP on the TV is old. Developer Mode stores the computer’s address. If the computer got a new IP, enter the new one and reboot the TV.
  • Device Manager will not connect. Same Wi-Fi, TV IP in Device Manager, computer IP on the TV, Connection set to On. A VPN on the computer often blocks this.
  • Install failed, or error 1010. Samsung says a certificate problem is a common cause. The usual case is an unsigned file, or a signature whose distributor certificate does not include this TV’s DUID. Add the DUID, sign again, and install the new signed file.
  • Certificate mismatch. The author certificate is not the one that signed the FEFC already on the TV. Sign with the original author certificate. If that file is lost, delete FEFC on the TV and install again with the new certificate. Keep the new author file.
  • A different TV. Add that TV’s DUID to the distributor certificate, sign again, and install that signed file. One signature does not cover a TV whose DUID was left out.
  • The app opens but video does not. The page still plays in the browser when the TV will not hand the stream to its hardware player. This package does not change the collection’s intro video.
