Update FEFC on an LG TV

The TV cannot install the new file by itself. A computer on the same Wi-Fi installs it with webOS Dev Manager. This replaces the app named FEFC. Its id stays org.xbmc.kodi.

These steps have not been tried on a real LG TV from this project. They follow LG’s Developer Mode app and the webOS Dev Manager desktop program.

What you need

  • The LG TV, turned on, with FEFC already installed.
  • A computer (Windows, Mac, or Linux) on the same Wi-Fi as the TV. A phone is a poor fit for this program.
  • The free Developer Mode app from the LG Content Store, signed in, with Dev Mode turned on.
  • webOS Dev Manager on the computer. Pick the Windows installer, the Mac disk image, or the Linux package for that computer. You do not need LG’s developer tools or a command line.

Where the new file is

The file is FEFC-webOS.ipk. The TV reads the address from platforms.webos in version.json. Use the link written on the TV update screen. When that entry is published, the address is:

https://fefc-collection.pages.dev/kodi-app/FEFC-webOS.ipk

If that link says the file is missing, the LG package has not been published yet. The TV still shows the new version number. Wait until the link on the TV screen downloads a file whose name ends in .ipk.

Install the update

  1. On the TV, open Developer Mode. If you have never used it: open the LG Content Store, search for Developer Mode, install it, sign in with an LG account, turn Dev Mode on, and let the TV restart. Open Developer Mode again.
  2. Turn Key Server on. Leave this screen up. Write down the IP address and the 6-character passphrase. The passphrase is case-sensitive.
  3. On the computer, download webOS Dev Manager and open it.
  4. On the computer, download FEFC-webOS.ipk from the link on the TV (the address above once it is published).
  5. In Dev Manager, add the TV. Choose the Developer Mode connection, not a rooted TV. Type the IP address as the host and the 6-character passphrase, then add the TV.
  6. Press Install and choose the FEFC-webOS.ipk file you just downloaded. Wait until it says the install finished. This replaces the existing FEFC app. It does not add a second copy.
  7. On the TV, fully close FEFC and open it again. The new version is the one that just installed.

Keep Developer Mode from expiring

The Developer Mode app shows a countdown. webOS Homebrew’s Dev Mode page currently describes that limit as 1000 hours. When the countdown reaches zero, LG removes apps that were installed this way, including FEFC.

Before it runs out, open Developer Mode on the TV and use the control on that screen to extend the session. The clock resets. You can also open the TV in Dev Manager and press Renew session. Do this while time is still left. One LG account can only keep Developer Mode on one TV. Signing that account in on a second TV turns it off on the first.

If the install fails

  • Dev Manager cannot add the TV. The computer and the TV must be on the same Wi-Fi. Read the IP again from the Developer Mode screen. Turn Key Server off, then on. Restart the TV, open Developer Mode, and turn Key Server on again.
  • It cannot fetch the key. On the computer, open http:// plus the TV’s IP plus :9991/webos_rsa in a browser. A key file should download. If the browser cannot connect, Key Server is off or the TV is not on this network.
  • Passphrase rejected. It is six characters and case-sensitive. Copy it from the Developer Mode screen, do not guess.
  • The .ipk link does not download. The LG package is still unpublished. Use only the platforms.webos link from the TV. Do not install the Android APK.
  • The TV says the package is the wrong type. This file is the 32-bit arm build. A set that only runs 64-bit apps cannot install it. webOS 4 and newer are the ones this build is for, except sets with the K5LP chip.
  • FEFC still looks old. Close it completely and open it again. If the tile is stale, turn the TV off and on.
  • FEFC disappeared. The Developer Mode countdown hit zero, or the LG account was used on another TV. Turn Developer Mode back on and install the file again with the same steps.

Why this program, and not the others

webOS Dev Manager is the one to use. It is a normal desktop program: you add the TV with the IP and passphrase, then you pick the .ipk file. No command line.

ares-install is the same connection typed as commands. It works, and it is a worse fit if you do not already use a terminal. Dev Manager is enough.

Homebrew Channel on a rooted TV can install an IPK from a web address without a computer. That installer is not on a normal Developer Mode TV. Rooting is a separate step, LG updates can close it, and FEFC does not require it. Stay with Dev Manager.
